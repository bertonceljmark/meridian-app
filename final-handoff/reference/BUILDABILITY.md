# Buildability: one native route per visual (pass 4a, 23 Oct; first written in pass 2a)

## Platform (pass 3)
- **iOS floor: 18.** The build relies on `onScrollGeometryChange` (the stage sink), `HKStateOfMind` (feel, optional write) and RealityKit `LowLevelMesh`.
- **3D on iPhone: RealityKit.** SceneKit is soft-deprecated (Apple's WWDC25 guidance points new 3D work to RealityKit; confirm against the current docs before the build starts). Every iPhone object is a `RealityView` whose meshes are generated from the user's data, with `LowLevelMesh` for anything that changes per log (route, columns, stones) and `MeshResource` for static parts. Picking uses `SpatialTapGesture().targetedToAnyEntity()` on entities that carry `InputTargetComponent` and `CollisionComponent`. No row below uses SceneKit APIs.
- **The Watch is flat SwiftUI only** (Path, Canvas, Gauge). It renders no 3D: watchOS has no RealityKit, and no Watch screen needs a turning object. Geometry generation (the route sweep, the stone lathe, the column prisms) lives in one Swift package that emits plain vertex and index buffers, so both renderers are fed from the same code.


Every visual in `meridian-src.html` draws from data the native app can read or already stores. Each line gives the visual, where it is, its data, and the native route. Ids follow review/r1/track7-buildability.md; N-xx are visuals that are new in pass 2a.

## The day boundary (AN-06)
The native day runs from wake to wake: an entry logged after midnight and before that night's sleep onset belongs to the previous day, and with no sleep data the boundary is 04:00. The prototype clock never runs past 23:30, so this case cannot occur in it and is specified here instead.


## LightGlass (pass 4a)
One flat component replaces the period stones (BD-11), observation stones (BD-12), the year turntable and the week-story stones. It is a row of vertical ribs drawn as light behind ribbed glass: each rib has a height, a hue (or several, as stacked bands), and a state (lit, quiet grey, frosted for set-aside, clear for future, current). Native route: SwiftUI `Canvas` (or Swift Charts `RectangleMark`) with a blurred gradient fill per rib and a static ribbed overlay image; it needs no RealityKit and runs on the Watch and in widgets as is. Data: Time = 52 weeks of `weekAims`; week story = 7 days × 12 two-hour bands; routine page = one rib per session against a fixed 60-min reference, slot ribs for counts, a 9-rib fill toward the aim for non-volume amounts.
